قالب فروشگاهی وردپرس/ووکامرس «فرشته مهربون» — تبدیل ۱۰۰٪ مطابق دموی ToyKind Angel.

== Description ==
* صفحه اول دمویی با داده واقعی (اسلایدر، استوری دسته‌ها، شگفت‌انگیز با تایمر، بنرها، جدیدترین، پرفروش، برندها) — تا درون‌ریزی دمو صفحه اصلی خالی است (استاندارد وردپرس)
* مرورگر دوستونه دسته‌بندی‌ها با جستجوی زنده
* نسخهٔ دسکتاپ و تبلت: منوی افقی، ظرف 1200px، PDP دوستونه، فوتر ۴ ستونه، فلش ریل‌ها — موبایل همچنان ۱:۱ دمو
* آرشیو محصول و صفحه محصول دقیقاً مطابق دمو (گالری، باکس گارانتی/موجودی، CTA چسبان، محصولات مشابه) — بدون بخش چندفروشندگی
* سبد/تسویه/حساب با استایل دمو و دکمه‌های +/− تعداد
* سئوی توکار: Schema (Organization/WebSite/Breadcrumb/Product/ItemList) + Open Graph/Twitter + canonical — با گارد خودکار افزونه‌های سئو
* سرعت: preload فونت/hero، lazy تصاویر، defer اسکریپت‌ها، بدون jQuery
* RTL کامل + فونت وزیرمتن (Vazirmatn متغیر، مجوز آزاد OFL)

== Installation ==
1. نمایش ← پوسته‌ها ← افزودن ← بارگذاری → toykindangel.zip → فعال‌سازی
2. افزونه WooCommerce را نصب و فعال کنید
3. نمایش ← درج محتوای نمونه ← دکمه «شروع درون‌ریزی» (منوها، دسته‌ها، محصولات و بنرهای دمو بازسازی می‌شوند) — یا «فقط برگه‌ها و تنظیمات» برای شروع با محصولات خودتان
4. راهنمای کامل: README.fa.md در بسته
